# Домашняя работа 3. Выбор ингредиентов для пиццы

## Данные для проверок

- Пепперони: 60 руб.
- Ветчина: 70 руб.
- Грибы: 50 руб.
- Лук: 30 руб.
- Оливки: 40 руб.
- Бекон: 80 руб.

Для проверок беру состояния с 0, 1, 4 и 5 выбранными ингредиентами.

## Список и цены

- Пользователь видит все шесть ингредиентов из списка.
- У каждого ингредиента указана цена, совпадающая со списком.
- В списке нет повторяющихся позиций.

## Добавление

Проверки добавления одного ингредиента повторить для каждой позиции из списка.

- При числе выбранных ингредиентов от 0 до 4 кнопка добавления невыбранного ингредиента доступна.
- После нажатия на кнопку добавления в составе появляется одна порция выбранного ингредиента.
- После добавления ингредиента его кнопка добавления заблокирована.
- Пользователь не может добавить вторую порцию того же ингредиента.
- Несколько быстрых нажатий на добавление одного ингредиента не создают дубликат.
- При выборе от 1 до 4 ингредиентов пользователь может добавить другой ингредиент.
- При переходе с 4 на 5 ингредиентов пятый ингредиент появляется в составе.
- При 5 выбранных ингредиентах кнопки добавления всех шести ингредиентов заблокированы.
- Попытка добавить шестой ингредиент не меняет состав: остаются 5 разных ингредиентов.
- Быстрые нажатия на добавление двух разных ингредиентов при 4 выбранных не позволяют получить 6 ингредиентов.

Проверку верхнего лимита повторить для шести наборов из пяти ингредиентов: в каждом наборе исключать одну позицию из списка.

## Удаление и повторное добавление

Удаление проверить для каждой позиции из списка, начиная с двух выбранных ингредиентов.

- Пользователь может удалить выбранный ингредиент; остальные ингредиенты остаются в составе.
- При удалении одного ингредиента из двух остаётся один ингредиент.
- При удалении одного ингредиента из пяти остаются четыре ингредиента.
- После удаления ингредиента его кнопка добавления становится доступной.
- После перехода с 5 на 4 ингредиента кнопки добавления невыбранных ингредиентов становятся доступными.
- Кнопки добавления ингредиентов, оставшихся в составе, остаются заблокированными.
- Пользователь может добавить удалённый ингредиент заново; в составе появляется одна его порция.
- Пользователь может заменить один из пяти ингредиентов: удалить его и добавить другой. В составе снова пять разных ингредиентов.
- Повторное нажатие на удаление уже удалённого ингредиента не удаляет другой ингредиент.

## Состояние без ингредиентов

Проверки выполнять при пустом составе.

- При отсутствии ингредиентов пользователь видит нотификацию с точным текстом: «Необходимо добавить хотя бы один ингредиент».
- При отсутствии ингредиентов кнопка удаления ингредиента заблокирована. Если у каждой позиции своя кнопка удаления, заблокированы все такие кнопки.
- Нажатие на заблокированную кнопку удаления не меняет состав и не вызывает ошибку.
- При отсутствии ингредиентов пользователь может добавить любую из шести позиций.
- После добавления первого ингредиента в составе одна его порция, кнопка добавления этой позиции заблокирована.
