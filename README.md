# Домашняя работа 2. User story для Telegram

## 1. Пересылка сообщения в «Избранное»

Как пользователь Telegram, я хочу переслать сообщение из чата в «Избранное», чтобы сохранить адрес или ссылку и не искать их в переписке.

Условия: пользователь вошёл в аккаунт. В обычном облачном чате есть текстовое сообщение со ссылкой, эмодзи и переносом строки. Пересылка разрешена.

Критерии приёмки:

1. Пользователь может выбрать сообщение, нажать «Переслать» и указать «Избранное» получателем.
2. После подтверждения отправки в «Избранном» появляется одна копия выбранного сообщения. Исходное сообщение остаётся в чате.
3. В копии сохраняются текст, переносы строк, эмодзи и адрес ссылки. Пользователь может открыть ссылку.
4. После закрытия и повторного открытия приложения пользователь видит сохранённое сообщение в «Избранном».
5. После синхронизации пользователь видит эту же копию на другом устройстве, где вошёл в тот же аккаунт.
6. Если во время пересылки нет сети, пользователь видит состояние ожидания отправки. После восстановления соединения сообщение отправляется, в «Избранном» появляется одна копия.

## 2. Поиск сообщения в «Избранном»

Как пользователь Telegram, я хочу искать сообщения в «Избранном» по слову, чтобы найти сохранённую запись без прокрутки всей истории.

Условия: пользователь вошёл в аккаунт. В «Избранном» есть сообщения «Встреча в пятницу», «Встреча в офисе» и «Купить билеты». В другом чате есть сообщение «Встреча в субботу».

Критерии приёмки:

1. Пользователь может открыть поиск внутри «Избранного» и ввести запрос.
2. По запросу «встреча» поиск находит оба сообщения с этим словом в «Избранном». Сообщение «Купить билеты» в результаты не попадает.
3. Сообщение «Встреча в субботу» из другого чата не попадает в результаты поиска по «Избранному».
4. Запросы «встреча» и «ВСТРЕЧА» дают одинаковый набор совпадений.
5. При выборе результата пользователь переходит к нужному сообщению в «Избранном» и может прочитать его целиком.
6. По запросу «электросамокат» пользователь видит, что совпадений нет. Результаты предыдущего запроса не отображаются.
7. После выхода из поиска пользователь возвращается к переписке в «Избранном»; сообщения сохраняются.
